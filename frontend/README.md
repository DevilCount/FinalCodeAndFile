# 实验室管理系统前端

基于Vue 3 + Element Plus的实验室管理系统前端项目，配合后端微服务架构使用。

## 技术栈

- **前端框架**：Vue 3 + Vite
- **UI组件库**：Element Plus
- **状态管理**：Pinia
- **路由管理**：Vue Router
- **HTTP客户端**：Axios
- **样式预处理器**：SCSS
- **图表库**：ECharts
- **表单验证**：VeeValidate

## 项目结构

```
frontend/
├── public/                 # 静态资源
├── src/
│   ├── assets/            # 资源文件
│   ├── components/        # 通用组件
│   ├── views/             # 页面视图
│   ├── router/            # 路由配置
│   ├── store/             # 状态管理
│   ├── services/          # API服务
│   ├── utils/             # 工具函数
│   ├── styles/            # 样式文件
│   ├── App.vue            # 根组件
│   └── main.js            # 入口文件
├── .env                   # 环境变量
├── vite.config.js         # Vite配置
├── package.json           # 项目依赖
└── README.md              # 项目说明
```

## 主要功能模块

1. **用户认证模块**
   - 登录/注册页面
   - 权限控制

2. **标本管理模块**
   - 标本创建
   - 标本查询（列表、详情）
   - 标本状态更新
   - 标本追踪记录

3. **报告管理模块**
   - 报告创建
   - 报告查询
   - 检验结果录入
   - 报告审核
   - 报告发布

4. **AI诊断模块**
   - AI辅助诊断
   - 血常规诊断
   - 尿常规诊断

5. **用户管理模块**
   - 用户列表
   - 用户编辑
   - 角色管理

6. **系统设置模块**
   - 系统配置
   - 日志管理

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发环境运行

```bash
npm run dev
```

### 构建生产环境

```bash
npm run build
```

### 预览生产构建

```bash
npm run preview
```

## 后端API对接

前端通过Axios与后端微服务API进行对接，主要对接以下服务：

- **用户服务**：`/user` 前缀
- **标本服务**：`/sample` 前缀
- **报告服务**：`/report` 前缀
- **AI服务**：`/ai` 前缀

所有API请求通过网关服务转发，基础URL配置在 `.env` 文件中。

## 响应式设计

系统采用响应式设计，支持PC端、平板和移动设备的适配，确保在不同屏幕尺寸下都能正常使用。
