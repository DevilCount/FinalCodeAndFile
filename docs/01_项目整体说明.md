## 1. 项目概述

### 1.1 项目简介

本项目是一个基于 **Spring Cloud Alibaba** 微服务架构的实验室管理系统（LIS），适用于中小型医院检验科。

### 1.2 核心功能

- ✅ 用户管理（临床医生、检验医师、管理员）
- ✅ 标本全生命周期管理（扫码追溯）
- ✅ 检验报告管理（AI辅助诊断）
- ✅ HL7标准接口对接
- ✅ AI辅助诊断（血常规、尿常规）

## 5. 开发环境配置

### 5.1 环境要求

- **JDK**: 17+
- **Maven**: 3.8+
- **Node.js**: 16+
- **MySQL**: 8.0+
- **Nacos**: 2.2+ (推荐独立部署)

### 5.2 后端环境配置

#### 5.2.1 安装JDK 17

下载并安装 JDK 17，配置环境变量：

```bash
JAVA_HOME=C:\Program Files\Java\jdk-17
Path=%JAVA_HOME%\bin
```

验证安装：
```bash
java -version
```

#### 5.2.2 安装Maven

下载并安装 Maven，配置环境变量：

```bash
MAVEN_HOME=C:\apache-maven-3.8.x
Path=%MAVEN_HOME%\bin
```

配置阿里云镜像（编辑 `settings.xml`）：

```xml
<mirror>
  <id>aliyunmaven</id>
  <mirrorOf>*</mirrorOf>
  <name>阿里云公共仓库</name>
  <url>https://maven.aliyun.com/repository/public</url>
</mirror>
```

验证安装：
```bash
mvn -version
```

#### 5.2.3 安装MySQL 8.0

下载并安装 MySQL 8.0，创建数据库：

```sql
CREATE DATABASE lab_management DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

执行初始化脚本：
```bash
mysql -u root -p lab_management < sql/init.sql
```

#### 5.2.4 安装Nacos

下载 Nacos 2.2.x：
https://github.com/alibaba/nacos/releases

启动 Nacos（standalone模式）：
```bash
# Windows
startup.cmd -m standalone

# Linux/Mac
sh startup.sh -m standalone
```

访问 Nacos 控制台：
http://localhost:8848/nacos

默认账号密码：nacos/nacos

#### 5.2.5 配置服务

各服务的 `application.yml` 配置文件：

**lab-gateway:**
```yaml
server:
  port: 8080

spring:
  application:
    name: lab-gateway
  cloud:
    nacos:
      discovery:
        server-addr: 127.0.0.1:8848
    gateway:
      discovery:
        locator:
          enabled: true
          lower-case-service-id: true
      routes:
        - id: user-service
          uri: lb://lab-user-service
          predicates:
            - Path=/api/user/**
        - id: sample-service
          uri: lb://lab-sample-service
          predicates:
            - Path=/api/sample/**
        - id: report-service
          uri: lb://lab-report-service
          predicates:
            - Path=/api/report/**
        - id: hl7-service
          uri: lb://lab-hl7-service
          predicates:
            - Path=/api/hl7/**
        - id: ai-service
          uri: lb://lab-ai-service
          predicates:
            - Path=/api/ai/**
```

**lab-user-service:**
```yaml
server:
  port: 8086

spring:
  application:
    name: lab-user-service
  cloud:
    nacos:
      discovery:
        server-addr: 127.0.0.1:8848
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://127.0.0.1:3306/lab_management?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: root
    password: your_password

mybatis-plus:
  configuration:
    map-underscore-to-camel-case: true
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl
```

其他服务配置类似，修改端口号和服务名即可。

## 8. 已知问题与解决方案

### 8.1 常见问题

#### Q1: Nacos连接失败？

**问题描述：** 服务启动时提示无法连接到Nacos

**解决方案：**
1. 确保Nacos已启动且访问地址正确
2. 检查 `application.yml` 中的配置：
```yaml
spring:
  cloud:
    nacos:
      discovery:
        server-addr: 127.0.0.1:8848
```
3. 检查防火墙设置

#### Q2: 数据库连接失败？

**问题描述：** 服务启动时提示数据库连接错误

**解决方案：**
1. 检查MySQL服务是否启动
2. 检查用户名密码是否正确
3. 检查 `application.yml` 中的配置：
```yaml
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/lab_management
    username: root
    password: your_password
```
4. 确保数据库已创建并执行了初始化脚本

#### Q3: 服务间调用失败？

**问题描述：** 一个服务调用另一个服务时失败

**解决方案：**
1. 确保所有服务都已注册到Nacos
2. 检查服务名是否匹配
3. 查看Nacos控制台确认服务状态
4. 检查服务是否正常启动

#### Q4: 注册时出现500错误？

**问题描述：** 前端注册功能返回500错误

**解决方案：**
1. 检查后端服务是否正常启动
2. 检查数据库连接
3. 查看后端日志定位具体错误
4. 当前端使用了模拟数据作为临时解决方案

#### Q5: 前端页面空白？

**问题描述：** 打开前端页面显示空白

**解决方案：**
1. 检查浏览器控制台是否有错误
2. 确认后端网关服务已启动
3. 检查 `.env` 配置文件中的API地址
4. 清除浏览器缓存重试

### 8.2 技术限制

1. **AI诊断**：当前使用基于规则的简单实现，非真实AI模型
2. **HL7接口**：仅实现基础消息解析，未对接真实HIS系统
3. **消息队列**：未引入消息队列，异步任务处理能力有限
4. **分布式事务**：未实现分布式事务，跨服务数据一致性需要手动保证
